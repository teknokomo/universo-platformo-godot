# Соответствие функционала с Universo Platformo React

**Цель**: Отслеживать соответствие реализации функционала между Universo Platformo React и данной реализацией на Godot.

**Ссылка на репозиторий**: [teknokomo/universo-platformo-react](https://github.com/teknokomo/universo-platformo-react)

**Последняя проверка**: 2025-11-16

---

## Статус реализации

### ✅ Реализованные функции

*Пока нет - выполняется начальная настройка*

### 🚧 В разработке

- [ ] **Настройка проекта и основа** (Godot: `001-project-setup`)
  - Структура репозитория
  - Двуязычная документация
  - Основа системы пакетов
  - Слой интеграции с базой данных
  - Шаблон базовых функций (Кластеры)

### 📋 Запланированные функции

*Будет заполнено после изучения репозитория React для выявления существующих функций*

**Следующие шаги**:
1. Выполнить глубокий анализ структуры репозитория React
2. Определить все реализованные функции в версии React
3. Расставить приоритеты функций для реализации в Godot
4. Создать спецификации для каждой функции с использованием `/speckit.specify`

### ❌ Неприменимо к Godot

- React-специфичные оптимизации (memo, useMemo, useCallback)
- Архитектура middleware Express (отличается в HTTP-сервере Godot)
- Конфигурация workspace npm/PNPM (Godot использует систему аддонов)
- Конфигурация сборки Webpack/Vite (Godot обрабатывает сборку внутренне)
- Определения типов TypeScript (GDScript использует нативную типизацию)

## Процесс мониторинга

1. **Еженедельная проверка**: Проверять репозиторий React каждый понедельник на наличие новых функций/изменений
2. **Создание issue**: Создавать отслеживающий issue в этом репозитории для новых функций React
3. **Оценка приоритета**: Оценивать актуальность и приоритет для реализации в Godot
4. **Спецификация**: Создавать детальную спецификацию с использованием рабочего процесса `/speckit.specify`
5. **Реализация**: Следовать стандартному рабочему процессу разработки (spec → plan → tasks → implement)
6. **Документация**: Обновлять этот файл при завершении реализации функции
